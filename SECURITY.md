# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities. Report privately through the GitHub Security tab using **Report a vulnerability**.

Include the affected version, platform, reproduction steps, impact, and a proposed mitigation when available. We will acknowledge reports within seven days and coordinate disclosure after a fix is available.
